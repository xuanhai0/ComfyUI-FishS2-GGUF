# Security

ComfyUI-FishS2-GGUF starts/controls local inference processes, writes files and exposes ComfyUI routes on your computer. Use it only in environments you trust.

- Keep ComfyUI and s2.cpp bound to trusted local interfaces; do not expose an unauthenticated server or ComfyUI instance to the public internet.
- Do not paste secrets or private voice reference material into public issues.
- Report security vulnerabilities privately to the maintainer (use GitHub's private vulnerability reporting if enabled).

No response-time or security-fix SLA is offered.
